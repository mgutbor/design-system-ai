# Badge

Etiqueta corta de estado en forma de píldora. El significado **siempre lo
transmite el texto**; el color solo lo refuerza (WCAG 1.4.1 — nunca color
como única señal).

## API

| Prop | Tipo | Default | Descripción |
|---|---|---|---|
| `variant` | `'neutral' \| 'success' \| 'warning' \| 'danger'` | `'neutral'` | Variante visual. |
| resto | atributos de `<span>` | — | `aria-*`, `role`, `data-*`, `ref`. |

## Variantes y contraste

Las variantes usan fondo sólido de `color.status.*` con texto
`color.text.on-action`. Ambos se adaptan al tema activo de forma automática;
los pares están validados contra WCAG 2.2 AA en light y dark (≥ 4.5:1, con
margen):

| Variante | Light (on-action sobre status) | Dark (on-action sobre status) |
|---|---|---|
| `neutral` | `text.default` sobre `surface.elevated` — 16.1:1 | — 13.3:1 |
| `success` | 5.0:1 | 7.8:1 |
| `warning` | 5.0:1 | 8.3:1 |
| `danger` | 6.5:1 | 6.4:1 |

## Accesibilidad

- El contenido textual es el significado (p. ej. "Approved", "Pending").
- Si el badge es el único indicador de un cambio de estado, añade
  `role="status"` (pasa a través del API nativa).
- Texto largo: los labels deben ser cortos (`white-space: nowrap`).
