# Checkbox

Casilla de verificación basada en el `<input type="checkbox">` nativo. Todo el
comportamiento accesible (teclado con Space, foco visible, estados
checked/disabled/required y el rol `checkbox`) lo aporta el propio elemento.

## API

| Prop | Tipo | Default | Descripción |
|---|---|---|---|
| `invalid` | `boolean` | `false` | Estado de error: `aria-invalid="true"` + anillo `color.action.danger`. |
| resto | atributos nativos de `<input>` | — | `checked`/`defaultChecked`, `disabled`, `required`, `value`, `name`, `aria-*`, `data-*`, `ref`. |

No hay más props propias: el `type` está fijado a `checkbox` (no es sobreescribible).

## Estados visuales

- **default**: casilla con `accent-color: color.action.primary`.
- **focus**: anillo `color.focus.ring` (solo `:focus-visible`).
- **disabled**: cursor `not-allowed`; no recibe foco ni interacción.
- **invalid**: anillo `color.action.danger` (sustituido por el anillo de foco mientras se enfoca).

## Accesibilidad

- El naming se resuelve con `FormField` (label + `htmlFor`) o con
  `aria-label`/`aria-labelledby` si se usa aislado.
- El estado de error se comunica con `aria-invalid` + texto visible (nunca
  solo color) — usa `FormField` para el mensaje.
- Teclado: Space para alternar (nativo).
