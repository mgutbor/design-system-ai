# FormField

Resuelve la asociación accesible entre **label**, **control**, **description**
y **error**. El componente genera un id estable (`useId`) y cablea los
atributos ARIA; el control (p. ej. `Input`) sigue siendo el único dueño de su
propio estado visual y de `aria-invalid`.

## API

| Prop | Tipo | Default | Descripción |
|---|---|---|---|
| `label` | `string` | — | Texto del label, asociado vía `htmlFor` + `id` del control. |
| `htmlFor` | `string` | id generado | Id explícito del control (para casos que necesiten determinismo externo). |
| `description` | `string` | — | Texto de ayuda cableado con `aria-describedby`. |
| `error` | `string` | — | Mensaje de error: reemplaza la description, se anuncia con `role="alert"` y activa `invalid` en el control. |
| `children` | `ReactElement<FormFieldControlProps>` | — | Un único control que implemente el contrato (p. ej. `Input`). |

## Cableado ARIA

- **label ↔ control**: `htmlFor` + `id` (asociación nativa, superior a `aria-labelledby`).
- **description ↔ control**: `aria-describedby` → `#id-description`.
- **error ↔ control**: `aria-describedby` → `#id-error` + `role="alert"` en el mensaje; el control recibe `invalid` (que activa `aria-invalid` y el estado visual).
- Si el control ya trae `aria-describedby`, se fusiona con el cableado del campo.
- Cuando existe `error`, la `description` no se muestra (el error la reemplaza).

## Contrato del control (`FormFieldControlProps`)

FormField inyecta exactamente tres props en el control: `id`, `aria-describedby`
y `invalid`. Cualquier control accesible que las declare es compatible sin
modificar FormField — es el mecanismo por el que `Select`, `Checkbox` y otros
controles podrán usarse en fases futuras sin acoplar este componente a ninguno
concreto. La responsabilidad visual del estado de error sigue viviendo en cada
control.

## Accesibilidad

- El error nunca se comunica solo con color: `aria-invalid` (máquina) + texto visible (persona).
- `role="alert"` anuncia el error al aparecer sin robar el foco.
- WCAG 2.2 AA: criterios 3.3.1 (error identification), 3.3.2 (labels), 1.3.1 (info and relationships).
